O que é uma variável?

Na programação, uma variável é como uma caixa onde guardamos uma informação para usar mais tarde.

Para não perdermos a nossa caixa, precisamos de colocar uma etiqueta com um nome nela.

*Dica: os nomes das variáveis não costumam ter espaços!

Muito bem!

Agora temos uma caixa chamada .

Mas está vazia! Vamos guardar um valor lá dentro. Pode ser um número ou uma palavra.

var =

Incrível!

Guardaste o valor na variável .

O nosso Robô assistente quer saber o que está na caixa. Clica no botão para ele a "ler"!

robo.ler();

O segredo das Variáveis!

Sabes porque se chamam variáveis? Porque o seu valor pode variar (mudar) a qualquer momento!

Tenta trocar o valor da caixa por outra coisa:

=

Minijogo: Oficina do Robô!

As variáveis bateria, alegria e limpeza diminuem com o tempo. Mantém-nas altas para o teu robô não avariar!

var bateria = 100;
var alegria = 100;
var limpeza = 100;
